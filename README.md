# my-first-app — مهامي

تطبيق مهام عربي باتجاه RTL باستخدام HTML وCSS وJavaScript فقط، دون مكتبات أو خطوات بناء.

## فتح التطبيق

افتح `index.html` في متصفح حديث، أو شغّل خادمًا محليًا من داخل مجلد المشروع:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الاستخدام

- اكتب المهمة واضغط «إضافة» أو Enter. الإدخال الفارغ والمسافات فقط غير مقبولين.
- اضغط مربع الاختيار لتحديد المهمة كمكتملة أو إعادتها للمهام المتبقية.
- اضغط أيقونة سلة المهملات لحذف المهمة.
- يظهر عدد المهام غير المكتملة ويتحدث تلقائيًا.
- تُحفظ المهام وحالة إكمالها في localStorage بالمفتاح `my-first-app.tasks.v1`.
- يمكنك اختيار موعد اختياري لكل مهمة وتعديله أو مسحه من القائمة. تُحفظ المواعيد بتوقيت الجهاز مع المهام، وتظل المهام القديمة متاحة.
- عند حلول الموعد يظهر تنبيه داخل التطبيق. زر «تفعيل إشعارات المتصفح» يطلب الإذن لإظهار إشعار نظام، إذا كان المتصفح يدعمه.
- يجب أن يظل التطبيق مفتوحًا للتذكير؛ لا توجد خدمة إشعارات بعد إغلاقه. قد تؤخر قيود الخلفية أو سكون الجهاز التنبيه، وتُراجع المواعيد مجددًا عند العودة للصفحة. تظهر المهام المتأخرة عند فتح التطبيق.

البيانات خاصة بهذا المتصفح والعنوان المستخدم؛ استخدم العنوان نفسه بعد كل تشغيل. حذف بيانات المتصفح يحذف المهام. عند تعذّر الحفظ يظهر تنبيه داخل التطبيق.

## الملفات

- `index.html`: بنية الواجهة العربية.
- `styles.css`: التصميم المتجاوب للكمبيوتر والموبايل.
- `app.js`: إدارة المهام والحفظ المحلي.
- `.openai/hosting.json`: إعداد المعاينة المحلية في بيئة Codex؛ يستخدم نسخة من ملفات الواجهة داخل `dist/`. بعد تعديل الملفات، انسخ `index.html` و`styles.css` و`app.js` إلى `dist/` لتحديث هذه المعاينة. لا تحتاج هذه الخطوة عند الفتح المباشر أو استخدام خادم Python.
